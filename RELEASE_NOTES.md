### Fixes & Improvements:

- **Feature (Multi-Platform Standalone Release):** Full standalone packages are now available across both Windows (10/11) and Linux distributions (Ubuntu, Debian, Fedora, Arch, Steam Deck). No external runtime installation is required.
- **Fix (Smart Focus & Color Picker Controls):** Sliders, custom tint inputs (`bc-tint-input`), and color picker controls no longer lose focus or get hijacked while clicking or dragging.
- **Fix (Neko Dark - Checkboxes & Notification Anchor):** Room preference checkboxes now render with clean native checkmarks, and new message notification badges adapt smoothly across landscape and portrait layouts.
- **Improvement (Addon Defaults):** Clean installations start with heavy optional addons disabled by default, giving players full control in Addon Manager.

### Downloads:

- **BC-Windows.exe (~160MB):** Self-contained single executable for Windows 10/11. No .NET runtime required. Just download and run.
- **BC-Windows-Hidden.exe (~160MB):** Same as Windows Standalone, but with no icon and a blank app name (Discreet mode).
- **BC-Linux.AppImage (~108MB) [Recommended]:** Portable single-file executable for Linux (Ubuntu, Debian, Fedora, Arch, Steam Deck). Just download, allow executing, and double-click.
- **BC-Linux-Hidden.AppImage (~108MB):** Same as Linux AppImage, with no icon and a blank app name (Discreet mode).
- **BC-Linux.tar.gz (~102MB) [Fallback]:** Portable archive for systems without FUSE or minimal distributions.
- **BC-Linux-Hidden.tar.gz (~102MB):** Same as Linux tarball, with no icon and a blank app name (Discreet mode).
