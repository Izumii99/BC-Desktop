### Fixes & Improvements:

- **Feature (Addon Manager Bookmarklet & History Runner):** Added a bookmarklet and custom script input bar in Addon Manager with saved history cache, one-click execution from history, optional startup auto-run, and a pop-up showing whether the script ran or failed.
- **Fix (R134 Tab-Out & Restraint Menu Display):** Fixed an issue in R134 where returning to the app after tabbing out could cause the character dialog or top-right restraint menu icons (such as activities and search) to turn blank black.
- **Fix (R134 Profile Screen Addon Crash Protection):** Fixed an issue in R134 where opening a player's profile or information sheet could trigger an unhandled error in third-party addons and freeze the game screen.
- **Fix (Update Notification & Release Notes):** Fixed update notifications and changelog previews so they always display clean, up-to-date release notes without raw markdown formatting.

### Downloads:

- **BC-Windows.exe (~160MB):** Self-contained single executable for Windows 10/11. No .NET runtime required. Just download and run.
- **BC-Windows-Hidden.exe (~160MB):** Same as Windows Standalone, but with no icon and a blank app name (Discreet mode).
- **BC-Linux.AppImage (~108MB) [Recommended]:** Portable single-file executable for Linux (Ubuntu, Debian, Fedora, Arch, Steam Deck).
- **BC-Linux-Hidden.AppImage (~108MB):** Same as Linux AppImage, with no icon and a blank app name (Discreet mode).
- **BC-Linux.tar.gz (~102MB) [Fallback]:** Portable archive for systems without FUSE or minimal distributions.
- **BC-Linux-Hidden.tar.gz (~102MB):** Same as Linux tarball, with no icon and a blank app name (Discreet mode).
